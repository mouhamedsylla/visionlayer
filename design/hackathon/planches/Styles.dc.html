Les styles d'architecture

Les blocs et leurs liens viennent toujours du code. Le style ne décide que de leur place sur la carte (S1), pour que ce qui compte dans ce style se voie sans chercher. Un style n'est jamais supposé.

Comment un style est reconnu
1

VisionLayer lit les points de contact

Routes, bases, files, appels entre déployables, importations entre dossiers. Sans modèle de langage.

2

L'assistant propose un ou plusieurs styles

Chaque raison est reliée à une ligne de code ou de configuration.

3

L'humain confirme ou corrige

La carte prend la disposition. Les styles se cumulent.

Les six dispositions ci-dessous sont des schémas : leurs noms (commandes, stock…) illustrent la forme. Sur un projet, chaque boîte est un vrai déployable lu dans le code.
